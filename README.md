# Consulta de CEP com Python 📍

Meu terceiro projeto desenvolvido em Python.

O programa permite consultar um CEP e exibe informações como cidade, bairro, rua e estado utilizando dados de uma API.

## Funcionalidades

- Consulta de CEP
- Validação do CEP digitado
- Busca de endereço através de API
- Tratamento de CEP inexistente
- Tratamento de erro de conexão
- Possibilidade de realizar várias consultas

## Tecnologias utilizadas

- Python
- Requests
- API ViaCEP
- JSON

## Como executar

Instale a biblioteca Requests:

pip install requests

Depois execute:

python main.py

## O que aprendi

Nesse projeto pratiquei integração com API, requisições HTTP, leitura de JSON, estruturas condicionais, loops e tratamento de erros.
